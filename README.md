# B42_WEB_047_-Cloud-Crafters
🎉 Event Management System
A web-based platform to streamline event creation, management, and registration. Designed for organizers to handle everything from planning to execution, and for users to browse and register for events easily.

🚀 Features
1. Create, edit, and delete events

2. Event categories (Workshop, Seminar, Concert, etc.)

3. User registration and booking system

4. Admin dashboard for event overview

5. Search and filter events

6. Responsive and mobile-friendly UI

🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript / React.js

Backend: Node.js, Express.js

Database: MongoDB / MySQL

Authentication: JWT / Session-based auth
